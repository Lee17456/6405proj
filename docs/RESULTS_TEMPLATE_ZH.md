## 可被数据支持或否定的预期

| 假设 | 支持它的证据 | 可能否定它的结果 |
|---|---|---|
| SVM 对短文本有很强性价比 | F1 接近深度模型且 pipeline 成本更低 | 明显损失 F1 或预处理成本较高 |
| Mamba 长输入显存增长较温和 | 匹配输入与精度下增长趋势更缓 | 实际实现或激活开销使优势不明显 |
| 更多上下文改善法律分类 | 同测试文档，2K/4K F1 高于 512 | 局部关键词已够用，新增文本没有收益甚至干扰 |
| Longformer 是有效长文对照 | 相同输入内容下能稳定训练并形成质量/成本差异 | 在当前数据和训练预算下不稳定或成本过高 |

没有必要强行让每个假设成立。不要提前写具体 F1、加速倍数或百分比显存节约。
